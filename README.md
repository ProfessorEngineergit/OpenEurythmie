# OpenEurythmie

Visualisierung von 13 Eurythmie-Formen für je drei Personen.

Öffne **index.html** im Browser, um alle Formen zu sehen.

- **●** Startpunkt - **→** Bewegungsrichtung
- Drei Farben kennzeichnen die drei Personen
